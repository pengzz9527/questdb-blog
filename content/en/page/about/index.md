# About Time-Series Lab

## Author Background

This site is maintained by an independent developer with 10+ years of data engineering experience, focused on time-series databases, IoT data, financial tick data, and observability.

| Domain | Experience |
|------|------|
| Time-series DBs (QuestDB / InfluxDB / TimescaleDB / ClickHouse) | 8+ years |
| IoT & sensor data pipelines | 6+ years |
| Financial high-frequency data (tick / L2 / OHLC) | 5+ years |
| Observability & monitoring (Prometheus / Grafana / QuestDB) | 5+ years |

## What This Site Does

In-depth QuestDB tutorials in both Chinese and English: from installation, ILP ingestion, SAMPLE BY aggregation, ASOF JOIN, symbol types, to Grafana dashboards, crypto-trading anomaly detection, and zero-cost self-hosted setups. All code is verified runnable in a real QuestDB environment (Docker).
