# Editorial Policy

Time-Series Lab's content standards, in short: **original, tested, reproducible**.

## Content Sources

- All articles are **original**, based on the author's hands-on experience + secondary creation from official QuestDB docs
- Code examples are verified runnable in a **real QuestDB environment** (Docker container)
- Performance data always includes test conditions (hardware, data scale, test date)

## Estimated vs Measured

- Measured data is labeled "measured" or includes a full test environment
- Speculative conclusions are explicitly labeled "estimated" or "expected," strictly separated from measured data
- No exaggeration, no speculation, no numbers without a source

## Update Frequency

- At least 1 new article per month
- Follow-up benchmarks within 2 weeks of major version releases
- If old content conflicts with latest QuestDB behavior, update immediately

## Corrections

- Report errors via Contact or GitHub Issues
- Verified corrections are updated in the original article within 24 hours and logged in the Correction Policy
