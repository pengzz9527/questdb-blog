# 关于 时序实验室

## 作者背景

本站由拥有 10+ 年数据工程经验的独立开发者维护，专注时序数据库、IoT 数据分析、金融 tick 数据与可观测性场景的实战。

| 领域 | 经验 |
|------|------|
| 时间序列数据库（QuestDB / InfluxDB / TimescaleDB / ClickHouse） | 8+ 年 |
| IoT 与传感器数据管线 | 6+ 年 |
| 金融高频数据（tick / L2 / K线） | 5+ 年 |
| 可观测性与监控（Prometheus / Grafana / QuestDB） | 5+ 年 |

## 本站定位

提供 QuestDB 的中文与英文深度实战教程：从安装部署、ILP 摄入、SAMPLE BY 聚合、ASOF JOIN、符号类型，到 Grafana 仪表板、加密交易异常检测、零成本自建方案。所有代码均在真实 QuestDB 环境（Docker 容器）中验证可运行。
