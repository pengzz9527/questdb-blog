# 编辑政策

时序实验室的内容标准，简单说就是：**原创、实测、可复现**。

## 内容来源

- 所有文章为**原创**，基于作者实战经验 + QuestDB 官方文档二次创作
- 代码示例均在**真实 QuestDB 环境**（Docker 容器）验证可运行
- 性能数据必附测试条件（机型、数据规模、测试日期）

## 推测 vs 实测

- 实测数据会标注"实测"或给出完整测试环境
- 推测性结论会明确标注"推测"或"预计"，与实测数据严格区分
- 不夸大、不臆测、不引用无出处的数字

## 更新频率

- 每月至少 1 篇新文章
- 重要版本发布后 2 周内跟进基准测试
- 发现旧文与最新 QuestDB 行为不符时，立即更新

## 纠错

- 发现错误请通过 联系我们 或 GitHub Issues 反馈
- 经核实的纠错会在 24 小时内更新原文，并在更正政策页留档
